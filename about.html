Memusatkan pantauan agent dan sumber riset Agent ID.

AgentRam adalah dashboard ringan untuk mencatat dan meninjau data agent, serta direktori sumber untuk menemukan lead mint dan kampanye yang berkaitan dengan Agent ID di BNB Chain.

Apa yang tersedia

  • Dashboard lokal untuk mengelola catatan agent, status, tingkat risiko, trust score, dan pencarian.
  • Panel lookup BNB ERC-8004 melalui API lokal dan indexer 8004scan.
  • Direktori sumber yang bisa dicari dan difilter menurut kategori.
  • Status pemeriksaan manual yang disimpan di browser pengguna.

Tujuan watchlist

Watchlist mengelompokkan katalog Agent ID, kalender mint, explorer, pengumuman, feed komunitas, pencarian sosial/web, dan beberapa tool riset. Tujuannya membantu menemukan lead serta memeriksa sumbernya—bukan menyatakan kampanye tertentu aman atau aktif.

Cara meninjau sebuah lead

  1. Mulai dari katalog, kalender, pencarian, atau postingan komunitas sebagai petunjuk saja.
  2. Temukan kanal resmi proyek dan cek bahwa pengumuman masih berlaku.
  3. Periksa jaringan, alamat kontrak, status/verifikasi kontrak, harga, eligibility Agent ID, supply, dan transaksi di explorer tepercaya.
  4. Anggap klaim “free” sebagai belum terverifikasi sampai biaya dan syaratnya dicek. Mint gratis tetap dapat memerlukan biaya gas.
  5. Jangan pernah memberikan seed phrase, private key, kata sandi, atau kredensial wallet kepada situs atau agent.

Batasan dan keamanan

AgentRam tidak otomatis memantau semua situs eksternal, memverifikasi klaim kampanye, atau mengeksekusi mint. Tautan komunitas dapat kedaluwarsa, salah, atau berbahaya. URL Boltbook kanonis dan tautan trycloudflare Agent Radar yang spesifik belum tersedia, sehingga entri tersebut ditandai sebagai placeholder pencarian.

API saat ini ditujukan untuk penggunaan lokal. Sebelum dipublikasikan di jaringan, ganti kredensial demo, amankan autentikasi, dan konfigurasi frontend ke backend yang dikelola dengan aman. GitHub Pages hanya menyajikan file statis dan tidak menjalankan Node API.
